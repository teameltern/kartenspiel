# Eltern-Kartenspiel: Wir gründen ein Familienunternehmen

Ein interaktives Kartenspiel für (frischgebackene) Eltern, um spielerisch Aufgaben zu verteilen und Tipps für die Teamarbeit zu erhalten.

## So wird gespielt
- Das Spiel läuft direkt im Browser.
- Paare können abwechselnd Karten anklicken, die einen "Job" im neuen Familienalltag darstellen.
- Ein grünes Häkchen markiert die Auswahl.
- Je nach Anzahl der gewählten Karten erscheinen hilfreiche und humorvolle Tipps im unteren Bereich.
